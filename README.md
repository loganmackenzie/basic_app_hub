# Basic App Hub

## Why

I hate the amount of bloated software and webpages and generally unhelpful apps that fail to solve core problems because of the amount of baggage that gets bundled. I just want simple, lightweight, single-responsibility tools. And that is why I have created these tools.

## Tools

- [Todo List App](https://loganmackenzie.github.io/basic_app_hub/todolist/index.html) - A simple todo list app that stores everything locally.
